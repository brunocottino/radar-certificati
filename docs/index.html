Certificati

I certificati compaiono qui appena il database risponde.

Prob. tenuta = probabilità stimata che tutti i sottostanti restino sopra la barriera capitale fino a scadenza (Monte Carlo su volatilità storica, correlazioni a 1 anno, drift 0, senza richiamo anticipato). Verde ≥85%, arancio 70–85%, rosso <70%. L'asterisco indica che è nota solo la distanza del peggiore: la stima è un limite superiore. Stime statistiche, non previsioni né consulenza. Dati anche via API JSON.

Distanze calcolate sul sottostante peggiore. Rend. a scadenza = cedole sul prezzo lettera + recupero verso 100, annualizzato, se tutte le cedole sono pagate. Rend. a richiamo = stesso calcolo alla prossima data di richiamo. Dati raccolti ogni mattina dai siti degli emittenti, indicativi. Non considera rischio emittente, fiscalità e cedole in memoria già maturate. Verifica sempre KID e term sheet dell'emittente.
